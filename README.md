# Runner's Progress Tracker

Runner's Progress Tracker is a web application that helps marathon runners monitor their race progress in real time. Enter your total race distance, distance covered, elapsed time, and target finish time to:

- Calculate your current average speed
- See the required speed to meet your target time
- View remaining distance and time
- Get instant feedback if you need to speed up or if you’re on track
- Track your race history for future reference

Perfect for athletes and coaches who want actionable insights during training or race day.
